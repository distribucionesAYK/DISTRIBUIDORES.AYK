# Distribuidores AYK — Demo web

Demo estática lista para Vercel.

## Publicar en Vercel
1. Subir esta carpeta a un repositorio de GitHub.
2. En Vercel: Add New > Project > importar el repositorio.
3. Framework Preset: Other.
4. Deploy.

No requiere build ni variables de entorno.
